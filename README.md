# Task Manager

React + Mantine + TanStack Query, FastAPI + SQLModel + SQLite. Чёрная тема, фиолетовый акцент `#7f49b4`, задачи, архив, дедлайны со временем и анимация выполнения.

## Запуск

```sh
docker compose up -d --build
```

Задачи: http://localhost:8080/ · Админка: http://localhost:8080/admin/

Кнопки перехода в админку в навигации task board нет. Адрес вводится вручную.

Маршруты отдельного Nginx:

| Путь | Назначение |
| --- | --- |
| `/` | Task board |
| `/api/` | API задач |
| `/admin/` | Админка |
| `/admin/api/` | API админки; документация `/admin/api/docs` |
| `/backend/` | Прямой префикс API task board, например `/backend/api/tasks` |
| `/telegram/`, `/gemini/`, `/codex/`, `/jev/`, `/collector/`, `/notifications/` | API соответствующего сервиса, например `/codex/status` |

Доступ к сервисам через внешние префиксы требует входа владельца в админке. Админка проксирует запросы с внутренним токеном, который не выдаётся браузеру. Остальные контейнеры не публикуют свои порты.

Интеграции по умолчанию выключены. Обычные задачи работают без ключей и аккаунтов. Наружу опубликован только порт отдельного сервиса `nginx`. API сервисов интеграций доступны внутри Compose и требуют внутреннюю авторизацию.

```sh
docker compose up --build --watch
```

Watch перезапускает изменённый Python-сервис; изменения frontend запускают его пересборку. После сборки обновите страницу. Для Watch нужен Docker Compose 2.23+.

## Настройка владельца

Скопируйте `.env.example` в `.env`. Задайте `ADMIN_PASSWORD` не короче 16 символов и постоянный ключ `INTEGRATION_ENCRYPTION_KEY`. Ключ Fernet можно сгенерировать стандартным Python:

```sh
python3 -c 'import base64, secrets; print(base64.urlsafe_b64encode(secrets.token_bytes(32)).decode())'
```

После изменения `.env` пересоздайте сервисы командой запуска. При доступе к VPS используйте HTTPS через свой reverse proxy и задайте `COOKIE_SECURE=true`. Пароль администратора вводится в админке; сессия хранится в HttpOnly cookie на 12 часов.

API-ключи, токены ботов и Telethon StringSession шифруются Fernet в SQLite. В браузер возвращается только признак наличия ключа; для замены введите новый, пустое поле сохраняет старый. Кнопка удаления ключа очищает его. Пароли 2FA и коды Telegram не сохраняются. Смена ключа шифрования без расшифровки старых данных сделает сохранённые секреты недоступными.

## Отдельные сервисы

| Каталог | Сервис Compose | Назначение |
| --- | --- | --- |
| `nginx/` | `nginx` | Единый reverse proxy, порт 8080 |
| `frontend/` | `frontend` | Статическая сборка task board |

| `admin/frontend/` | `admin-frontend` | Отдельная сборка админки `/admin/` |
| `admin/backend/` | `admin-backend` | Авторизация владельца, настройки, подтверждение и запуск действий |
| `services/telegram/` | `telegram` | Пользовательский аккаунт через Telethon |
| `services/collector/` | `collector` | Бот-сборщик на aiogram |
| `services/notifications/` | `notifications` | Отдельный бот уведомлений на aiogram |
| `services/gemini/` | `gemini` | Google Gen AI SDK, структурированное извлечение задач |
| `services/codex/` | `codex` | Официальный Python SDK `openai-codex`, подготовка материалов |
| `services/jev/` | `jev` | Официальный Python SDK Cloudflare, модель Jev |

У каждого сервиса собственные `main.py`, `requirements.txt` и Dockerfile. Переключения ролей в одном backend нет. Общий код не запускает провайдеров. Redis, брокеры очередей и локальные модели не используются; каждый процесс работает асинхронно.

## Telegram и Gemini

В карточке Telegram доступны три независимых подключения:

1. **Пользовательский аккаунт Telethon.** Сохраните API ID и API Hash с my.telegram.org и телефон. Запросите код, введите код и при необходимости пароль 2FA. Загрузите чаты и явно разрешите нужные. Автоматическое чтение начинается с момента выбора; вся история аккаунта не загружается. Ручной анализ получает до 50 последних сообщений за 7 дней в выбранном чате.
2. **Бот-сборщик aiogram.** Создайте отдельного бота у BotFather, сохраните его токен и включите. Добавьте его в нужные группы/каналы. Для обычных сообщений групп отключите Privacy Mode; у каналов должны быть выданы нужные разрешения. Отправьте новое сообщение, загрузите обнаруженные чаты бота и разрешите нужные. До выбора сохраняются только названия чатов. Bot API не даёт произвольно читать личные переписки пользовательского аккаунта и не загружает историю. Очередь ограничена последними 500 сообщениями на чат; переполнение отображается в статусе.
3. **Бот уведомлений aiogram.** Используйте другой токен BotFather. Укажите числовой Telegram ID владельца, включите бота и напишите ему `/start`. Напоминания о приближающемся и просроченном дедлайне, новых предложениях и готовых материалах Codex отправляются только владельцу. Повторная отправка подавляется сохранёнными ключами; при аварии между отправкой и фиксацией в SQLite возможен повтор.

В карточке Gemini сохраните API-ключ, загрузите список доступных моделей, выберите модель с поддержкой structured output и проверьте подключение. Укажите часовой пояс IANA, например `Europe/Moscow`, и контекст владельца: имя, учебную группу и какие поручения относятся к вам. Включите Gemini и автоматический анализ нужного источника. Проверка модели делает настоящий запрос и расходует квоту.

Сообщения обрабатываются пакетами по чатам, с контекстом последних десяти сообщений. Текст контекста и очередь бота зашифрованы. Сохраняются ID обработанных сообщений, ключи предложений и принятые решения. При ошибке API пакет не помечается обработанным и может быть повторён. Одинаковое название новой задачи в том же чате не создаётся повторно автоматически.

Автосоздание разрешено только для уверенно распознанной новой задачи с явным адресатом-владельцем и без неоднозначности. Изменения, уточнения сроков, отмена и неоднозначные задачи всегда попадают в «На подтверждение». Их можно принять, отредактировать или отклонить; для изменения/отмены можно выбрать существующую задачу. Отмена переносит задачу в архив. Ссылка на исходное сообщение сохраняется там, где Telegram позволяет её сформировать.

## Codex

Используется официальный Python SDK [`openai-codex`](https://developers.openai.com/codex/sdk/) с закреплённой зависимостью CLI runtime. Подключение — официальный [device code login](https://developers.openai.com/codex/auth/) по подписке ChatGPT; включите его в настройках безопасности ChatGPT. Никаких собственных OAuth-механизмов или извлечения токенов нет. Доступ зависит от тарифа, политики аккаунта и лимитов.

В админке включите агента. Кнопка в задаче открывает защищённые действия Codex/Jev. Можно также открыть их сразу после сохранения ручной задачи. Только по отдельному переключателю разрешается автоподготовка принятых задач из Telegram.

Обрабатывается одна задача одновременно, не дольше пяти минут. Кодекс получает только название и описание как недоверенные данные через `ExternalMessage`. Он работает под отдельным UID в своём контейнере, с `workspace-write`, запретом повышения разрешений и сетевого доступа shell-команд. Встроенный поиск работает в режиме cached. База, Telegram-сессии, ключи Gemini/Cloudflare и токены ботов в этот контейнер не монтируются. Окружение дочернего процесса очищено. Docker socket не передаётся.

**Linux sandbox должен поддерживаться ядром VPS и настройками контейнеров.** Если проверка sandbox не проходит, выполнение блокируется. Не включаются `privileged`, `danger-full-access` или отключение seccomp. «Проверить доступность» делает реальный запрос модели. Авторизация и работа без аккаунта не имитируются.

Материалы сохраняются в отдельной рабочей директории, показываются и скачиваются в админке. Успешная подготовка переводит задачу в статус «На проверку», но не «Выполнено». Публикации, отправка сообщений и другие внешние изменения не разрешены. Прерванные при перезапуске задания требуют ручного повторного запуска.

## Jev

Используется официальный [Cloudflare Python SDK](https://github.com/cloudflare/cloudflare-python) и опубликованный API модели [`typesafe/jev`](https://developers.cloudflare.com/ai/models/typesafe/jev/). Нужны Account ID и API-токен с правом выполнения AI-запросов. Кнопка проверки отправляет настоящий запрос.

Модель оценивает важность, срочность, сложность и необходимость выполнения в ближайшее время. Численный приоритет 0–100 вычисляется из важности (40%), срочности (35%) и необходимости выполнения (25%); сложность сохраняется отдельно. Ручной приоритет не меняется. Сортировка Jev выбирается отдельно; после отключения интеграции используется обычный приоритет. Просроченные незавершённые задачи остаются первыми.

У Workers AI есть [бесплатный лимит](https://developers.cloudflare.com/workers-ai/platform/pricing/), но карточка Jev обозначена как сторонняя модель с отдельной ценой. Бесплатная доступность именно Jev для вашего аккаунта не гарантируется: это выясняется проверкой. При отказе авторизации, исчерпании квоты или недоступности провайдера обычные задачи продолжают работать.

## Данные и API

Существующий каталог `./data` сохраняется и содержит `tasks.db`. При запуске добавляются недостающие таблицы/колонки без удаления задач. Несколько сервисов используют тот же файл SQLite с WAL и ожиданием блокировки. Настройки и зашифрованная сессия сохраняются после перезапуска. Данные Codex хранятся в volumes `codex-home` и `codex-work`. Сохраняйте резервную копию `./data`, ключа шифрования и этих volumes; не добавляйте `.env` и `data` в git.

API задач: `GET/POST /api/tasks`, `GET/PATCH/DELETE /api/tasks/{id}`. `DELETE` отправляет в архив; `?permanent=true` удаляет уже архивную задачу. Восстановление: `PATCH` с `{"archived": false}`. Архив: `GET /api/tasks?archived=true`.

Фильтры: `status=todo|in_progress|review|done`, `priority=low|medium|high|overdue`, `category=Название`. Сортировка: `sort_by=deadline|priority|created_at|ai_score`, `order=asc|desc`. Высший ручной приоритет первым — `priority&order=asc`, оценка Jev — `ai_score&order=desc`. Просроченные задачи идут первыми при любой сортировке; без дедлайна — в конце при сортировке по дедлайну. Оценка Jev отсутствующих значений помещается в конец.

Время API — ISO 8601, хранение UTC; интерфейс показывает локальное время браузера. Старые даты без времени переводятся в 23:59 указанной даты по UTC. Ручной приоритет сохраняется при вычислении просрочки.

Защищённые API: `/admin/api/integrations`, `/admin/api/inbox`. Авторизация: `POST /admin/api/auth/login` с `{"password":"…"}`. Ключи из API не выдаются. Базовые CRUD-маршруты task board сохраняют прежнее поведение без входа; при публичном размещении ограничьте доступ к самому сайту своим reverse proxy/VPN.

Проверки внешних сервисов требуют ваших ключей и аккаунтов. Без них нельзя подтвердить подключение, квоту, доставку уведомлений или выполнение задачи моделью.
